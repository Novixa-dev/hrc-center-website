# Sprint 0 — Discovery & Setup

**Goal:** Produce everything needed to build the HRC website with confidence — research,
plans, a drafted design system, skill rules, dev guides, trackers, and sprint scaffolding —
before any application code.

**Depends on:** the client brief (`idea.md`).
**Blocks:** all other sprints.

## Scope

### In
- Internet + social research on HRC, Al‑Ahgaff University, Novixa, and peer institutions.
- Consolidated research files with confidence tagging.
- Planning docs: master plan, PRD, IA, content strategy, technical architecture, sprint
  plan, Definition of Done, risk register.
- Vendored design/UX skills + a documented inventory and binding usage rules.
- A guide on which `.md` artifacts help an AI build well (spec‑driven dev).
- Dev guides: git workflow, coding standards, SEO checklist.
- Design brief + system drafts (brand/voice, tokens, typography, motion, a11y, components).
- Test strategy + master QA checklist.
- Global progress tracker + global report.
- Sprint templates + this Sprint 0 folder + the content review checklist.
- Repo scaffold (tooling config, README, CLAUDE.md).

### Out (this sprint)
- Finalizing the design system → **S1** (drafts only here).
- Any `src/` application code, config, or dependencies → **S2**.
- Writing page content → **S3–S6**.
- Building the Novixa case study / social kit → **S9**.
