# Security Policy

## Supported Versions

The following version of the Hadramout Research Center website is currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The security and integrity of the Hadramout Research Center web platform are of the utmost importance.

If you discover a security vulnerability, please report it privately:

1. **Do not disclose the issue publicly** in GitHub Issues, pull requests, or social media.
2. Send an email with a detailed description of the vulnerability, reproduction steps, and any proof-of-concept to:
   - **Novixa Security Team:** `security@novixa.dev`
   - **HRC Technical Liaison:** `info@hrc-ahgaff.org`
3. We will acknowledge receipt of your vulnerability report within 48 hours and provide an estimated timeline for a resolution.
4. Once a fix has been tested and deployed to production, we will publish a security advisory and credit the reporter.

Thank you for helping keep HRC's digital assets safe.
